I've completed 20+ projects spanning GPIO, timers, DMA, SPI, I2C, UART, watchdogs, bootloader modification, and FreeRTOS — debugging real hardware issues like HardFaults, EXTI conflicts, and DMA restart logic along the way.

I'm drawn to the layer where a single register write controls a physical voltage level and timing matters in nanoseconds. My goal is to build embedded systems that are reliable, efficient, and genuinely close to the metal.

Embedded Firmware Featured
STM32 Embedded Systems: Full Peripheral Stack
A comprehensive, hands-on firmware portfolio built on the STM32F407G-DISC1 (ARM Cortex-M4, 168 MHz), progressing deliberately from HAL abstractions to bare-metal register-level control without HAL or CubeMX. Every project targets a real peripheral problem, verified on hardware. Real bugs encountered and solved: voltage divider pull resistor conflicts, DMA restart edge cases, ISR timing races, watchdog window violations, and USB DFU boot sequencing. All projects developed on Linux with a logic analyzer, ST-LINK/V2-A, and a SEGGER J-Link Pro.
Key Projects
•FreeRTOS on hardware (CMSIS-OS v2) - tasks, queues with backpressure, binary and counting semaphores, mutexes with starvation testing, event flags for AND-logic synchronization, and a real sensor pipeline combining a touch sensor and laser module with dual queue fan-out - verified on STM32F407
•20+ firmware projects spanning GPIO, timers, PWM, ADC, DAC, SPI, I2C, UART, DMA, watchdogs, and bootloader modification using both HAL and direct register access
•MEMS_TiltLEDs capstone - real-time tilt indicator combining SPI DMA burst reads, DRDY interrupt via EXTI, TIM2 calibration animation, and button-triggered baseline capture from onboard LIS3DSHTR accelerometer. Debugged EXTI line conflict: PA0 and PE0 both on EXTI line 0
•Bare-metal TRNG - direct register pointer casting against RM0090, no HAL, no CubeMX - demonstrates ability to work from reference manual at the register level
•Portable SPI + I2C driver libraries - handler/struct abstraction pattern, struct members derived from HAL signatures, internal helpers hidden from public API, reusable across peripherals
•USB DFU bootloader - software jump to ROM bootloader via persistent 0xDEADBEEF flag in .noinit linker section, VTOR remapping, verified with STM32CubeProgrammer
•IWDG + WWDG watchdogs - deliberate failure mode testing on hardware: early kick and late kick cases both confirmed on WWDG, reset cause detection via RCC_CSR flags
•PWM input capture - TIM4 generates 1kHz at 30% duty, TIM3 measures via input capture - self-verified frequency and duty cycle over UART without external equipment
